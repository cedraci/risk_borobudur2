# Borobudur Risk — user guide

Borobudur Risk is a risk-monitoring dashboard for UCITS funds and mandates. It
imports the weekly "NAV Recap" workbook and/or CACEIS Bank Luxembourg CSV
exports, and computes performance, P&L attribution, VaR/ES, UCITS limit
checks, liquidity, and EMIR monitoring per portfolio.

The guide is split by topic — one chapter per tab of the tool, plus the
cross-cutting chapters on getting started and access rights.

| Chapter | What it covers |
| --- | --- |
| [Getting started](getting-started.md) | Installing and running the tool, desktop vs server mode, signing in, enrolling your account, finding your way around. |
| [Overview](overview.md) | The landing dashboard: headline KPIs and the NAV chart. |
| [Performance](performance.md) | Return tables and performance statistics. |
| [P&L](pnl.md) | Period P&L attribution by instrument and grouping, with the reconciliation to the fund's AUM change. |
| [Risk](risk.md) | Volatility, drawdown and related risk statistics. |
| [VaR / ES](var-es.md) | Value-at-Risk and Expected Shortfall (three methods), UCITS monitoring, and VaR back-testing. |
| [Limits](limits.md) | UCITS concentration checks, liquidity bucketing and redemption stress, bond analytics (YTM, duration, DV01) and NAV rate sensitivity. |
| [Breaches](breaches.md) | The persistent breach register: runs, episodes, proposed classifications, acknowledge/resolve, and the evidence export. |
| [Derivatives](derivatives-emir.md) | Notional exposure by underlying and category, and EMIR clearing-threshold monitoring with the evidence export. |
| [Data](data.md) | All imports (NAV Recap, CACEIS CSV, CTD analytics, Bloomberg classifications), futures contract confirmation, reference data, portfolio management, and the shareholder register. |
| [Administration](administration.md) | Server mode only: users, enrolment, roles, grants, sessions, and the audit log. |
| [Access rights](access-rights.md) | How permissions work: domains, actions, portfolio scope, roles, and how denied data looks on screen. |
